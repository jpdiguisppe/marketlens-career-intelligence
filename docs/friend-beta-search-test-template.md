# MarketLens cross-sector friend beta

Record only the search behavior. Do not collect résumé text, account identifiers, or private application details.

| Field | Allowed value |
|---|---|
| Occupation query | The exact role text entered |
| Location | City/state, state, remote, or blank |
| Level | Any, intern, entry, mid, or senior |
| Interpretation | Correct, ambiguous clarification, or incorrect |
| Results | Relevant, partly relevant, irrelevant, or none |
| Failure category | Interpretation, precision, public-source coverage, provider failure, location, or level |
| Notes | Brief description without personal data |

## Suggested coverage

Test at least one occupation in each available friend sphere, including finance, accounting, law enforcement, healthcare, business, skilled trades, multiple engineering disciplines, education, law, marketing, sports, and economics.

For an empty result, confirm whether MarketLens says it understood the occupation and explains public-source availability, rather than treating every empty search as the same failure.
